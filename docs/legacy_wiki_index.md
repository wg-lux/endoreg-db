# Historical GitHub Wiki references

The links below point to older GitHub Wiki pages retained from the original
README. They may provide historical context, but repository-maintained
documentation is the source of truth for current behavior. Production
readiness belongs to the [feature tracker](../feature-tracking/README.md).

Before relying on an old page, check the [documentation index](README.md) for a
maintained successor. Pages about production operation, security, API behavior,
or patient data should not override current repository contracts.
